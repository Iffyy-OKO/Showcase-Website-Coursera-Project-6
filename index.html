Pink Beauty Products Showcase Wireframe Report

Student: Ifeoma Grace Okonkwo | Module: User Interface Design

Project Description

The Pink Beauty Products Showcase Website is a responsive beauty and skincare website developed to present beauty products in a modern and user-friendly layout.

The goal of the project is to create a clear website structure that allows users to browse products, discover beauty tips, and access wishlist functionality without distractions.

Two responsive wireframes were created: Desktop View and Mobile View. The desktop layout uses a wider multi-column structure, while the mobile layout uses a single-column design for smaller screens.
